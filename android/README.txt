NEXUS SMIS Android app (opens https://kenyansmis-8jwcu8tn.manus.space/)
Build: create a GitHub repo, upload these files, open Actions > "Build NEXUS APK" > Run workflow,
then download the "NEXUS-SMIS-apk" artifact (app-debug.apk). On the phone: open the APK and allow
"Install unknown apps". Or open this folder in Android Studio and run Build > Build APK.
